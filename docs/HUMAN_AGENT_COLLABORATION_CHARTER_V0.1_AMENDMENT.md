# 人类—Agent 协作宪章：Protocol v0.1 兼容性补充

**适用版本：Protocol v0.1**  
**依据：人类决定 D006、D012**

本补充文件与 `HUMAN_AGENT_COLLABORATION_CHARTER.md` 共同适用。出现不一致时，本补充仅在 Protocol v0.1 的以下范围内优先：

1. 变更分类从六类扩展为七类，新增 `CAPABILITY_ENVELOPE_CHANGE`；
2. Capability Envelope 的扩大、收缩、续期和失效不再归入 `ASSURANCE_CHANGE`；
3. Agent 可以提出能力边界变化，但不得批准或部署自己的高风险提案；
4. Protocol v0.1 通过 `pilot-check` 后只获得工程试点权限；
5. 未通过 `freeze-check` 时，Agent 和人类均不得把工程试点解释为正式确认性实验；
6. D007 的 T0–T3 细则是保守工程实现，不得冒充为人类在原评论中逐项批准的原文；改变其规范性含义需要显式 Amendment。

其余目标、授权、证明、独立审查、失败保留和 Sealed Test 条款继续按主宪章执行。
