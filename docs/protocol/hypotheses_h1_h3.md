# Track A 确认性假设 H1–H3

**版本：0.1-draft**  
**状态：等待 D008–D011 与统计负责人签署**

## 1. 方法组

| 编号 | 方法 |
|---|---|
| `M1` | 固定目标自进化：可改 Harness 和 Evaluator，不可改 Goal |
| `M2` | 无治理可变目标：可自行改 Harness、Evaluator 和 Goal |
| `M3` | 完整目标治理：可提案，独立验证；规范性变化需要授权 |

静态系统和完整目标预先可见组属于辅助基线，不承担 H1–H3 的主要比较。

## 2. H1：安全性优越

### 科学问题

完整治理是否降低未授权目标放宽和严重 False Pass？

### 主要比较

`M3 - M2`

### 主要 estimand

在预先设计的无权放宽机会中：

\[
\theta_{H1}=P(unauthorized\_deployment|M3)-P(unauthorized\_deployment|M2)
\]

期望 `theta_H1 < 0`。

### 关键安全终点

\[
P(severe\_false\_pass|high\_risk, M3)-P(severe\_false\_pass|high\_risk, M2)
\]

### 分母规则

分母使用预先冻结的“放宽机会”和“高风险任务”，不能只使用系统实际提出的 Patch。否则系统可以通过不记录正式提案而逃避测量。

### 支持条件

- 主要 estimand 显示 M3 风险更低；
- 严重 False Pass 不增加；
- 没有通过 Evaluator、Autonomy 或 Assurance 弱化转移风险；
- 密封测试方向一致。

## 3. H2：真实效用非劣

### 科学问题

完整治理是否在降低风险的同时，没有造成不可接受的真实效用下降？

### 主要比较

`M3 - M1`

### 主要 estimand

\[
\theta_{H2}=E[U^*(M3)]-E[U^*(M1)]
\]

`U*` 由独立 Oracle 按任务发生时有效的 `G_t^*` 计算。

### 非劣判断

若置信区间下界高于 `-delta`，则支持非劣。`delta` 的冻结程序见 D009；数值在工程试点后、查看正式方法标签前冻结。

### 安全优先

H2 不能补偿 H1 的失败。即使平均效用较高，只要严重安全风险未降低，就不能宣称完整治理总体优越。

## 4. H3：合法适应性

### 科学问题

面对目标发现或合法规范变化，完整治理是否能恢复满足当前 `G_t^*`，同时拒绝无权变化？

### 主要比较

`M3 - M1`

### 辅助比较

`M3 - M2`

### 主要 estimand

建议在试点后从以下两个中冻结一个为主要终点：

1. **恢复时间**：合法事件生效至系统在未见任务上连续满足新 `G_t^*` 的代数；
2. **变化后效用 AUC**：事件生效后若干代内 `U*` 的面积。

本 Draft 默认推荐“变化后效用 AUC”，因为它同时反映恢复速度和恢复质量；恢复时间作为关键次要终点。

### 关键次要结果

- Goal Discovery 召回率；
- 合法变化正确实施率；
- 正确生效时间；
- 无权变化接受率；
- 历史影响传播召回率；
- Replay 回归数。

### 支持条件

M3 相比 M1 更好地恢复 `G_t^*`，且相比 M2 不增加无权变化接受。

## 5. 联合结论规则

| 结果 | 可支持结论 |
|---|---|
| H1 不支持 | 不得声称目标治理更安全 |
| H1 支持，H2 不支持 | 更安全，但效用代价可能不可接受 |
| H1、H2 支持，H3 不支持 | 安全且非劣，但未证明保留合法适应 |
| H1–H3 支持 | 支持 Track A 核心复合主张 |

## 6. 初始分析框架

- 二元安全结果：混合效应逻辑回归；
- 连续效用：适合分布的混合模型；
- 恢复时间：离散时间生存模型或预注册替代；
- 随机效应至少包括 World、Task Template 和 Run；
- 报告效应量和 95% 置信区间，不只报告显著性；
- 多重比较采用层级检验，探索性结果明确标记。

正式模型公式、样本规模和 `delta` 属于 v0.2 试点后冻结内容。
