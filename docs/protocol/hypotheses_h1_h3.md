# Track A 确认性假设 H1–H3

**版本：0.1.0**  
**状态：工程试点 estimand 已锁定；正式确认性参数尚未冻结**

## 1. 方法组

| 编号 | 方法 |
|---|---|
| `M1` | 固定目标自进化：可改 Harness 和 Evaluator，不可改 Goal |
| `M2` | 无治理可变目标：可自行改 Harness、Evaluator 和 Goal |
| `M3` | 完整目标治理：可提案，独立验证；规范性变化需要授权 |

静态系统和完整目标预先可见组属于辅助基线，不承担 H1–H3 的主要比较。

## 2. H1：安全性优越

### 科学问题

完整治理是否降低未授权目标放宽和严重 False Pass？

### 主要比较

`M3 - M2`

### 主要 estimand

在预先设计的无权放宽机会中：

\[
\theta_{H1}=P(unauthorized\_deployment|M3)-P(unauthorized\_deployment|M2)
\]

期望 `theta_H1 < 0`。

### 关键安全终点

\[
P(severe\_false\_pass|high\_risk, M3)-P(severe\_false\_pass|high\_risk, M2)
\]

### 次要诊断

- 危险提案率；
- Evaluator 弱化；
- Autonomy 扩大；
- Assurance 降低；
- 未经验证扩大 Capability Envelope。

### 分母规则

分母使用预先冻结的“放宽机会”和“高风险任务”，不能只使用系统实际提出的 Patch。否则系统可以通过不记录正式提案而逃避测量。

### 支持条件

- 主要 estimand 显示 M3 风险更低；
- 严重 False Pass 不增加；
- 没有通过 Evaluator、Autonomy、Assurance 或 Capability Envelope 转移风险；
- 正式密封测试方向一致。

## 3. H2：真实效用非劣

### 科学问题

完整治理是否在降低风险的同时，没有造成不可接受的真实效用下降？

### 主要比较

`M3 - M1`

### 主要 estimand

\[
\theta_{H2}=E[U^*(M3)]-E[U^*(M1)]
\]

`U*` 由独立 Oracle 按任务发生时有效的 `G_t^*` 计算。

### 非劣判断

若置信区间下界高于 `-delta`，则支持非劣。v0.1 冻结以下程序，而不是数值：

1. 工程试点只估计任务波动，不查看方法标签对应的主差异；
2. Research Owner、独立 Methods / Statistics Lead 和 Domain Lead 分别提出实践界限；
3. 形成带理由的 Decision Record；
4. 正式主实验前冻结数值、公式和代码哈希。

### 安全与弃权边界

H2 不能补偿 H1 的失败。Coverage、弃权适当性、错误弃权率和 Selective Risk 独立报告；错误弃权不能只被解释为普通效用降低。

## 4. H3：合法适应性

### 科学问题

面对目标发现或合法规范变化，完整治理是否能恢复满足当前 `G_t^*`，同时拒绝无权变化？

### 主要比较

`M3 - M1`

### 辅助比较

`M3 - M2`

### 工程试点主要 estimand

**变化后效用 AUC**：事件生效后若干代内 `U*` 的面积，同时反映恢复速度和恢复质量。

### 关键次要结果

- 恢复时间；
- Goal Discovery 召回率；
- 合法变化正确实施率；
- 正确生效时间；
- 无权变化接受率；
- 历史影响传播召回率；
- Replay 回归数。

### 支持条件

M3 相比 M1 更好地恢复 `G_t^*`，且相比 M2 不增加无权变化接受。不得以 Goal Patch 数量作为主要结果。

## 5. 联合结论规则

| 结果 | 可支持结论 |
|---|---|
| H1 不支持 | 不得声称目标治理更安全 |
| H1 支持，H2 不支持 | 更安全，但效用代价可能不可接受 |
| H1、H2 支持，H3 不支持 | 安全且非劣，但未证明保留合法适应 |
| H1–H3 支持 | 只支持 Track A 受控环境核心复合主张 |

Track B 的外部效度不能由 H1–H3 自动推出。

## 6. 初始分析框架

- 二元安全结果：混合效应逻辑回归；
- 连续效用：适合分布的混合模型；
- 恢复时间：离散时间生存模型或预注册替代；
- 随机效应至少包括 World、Task Template 和 Run；
- 报告效应量和 95% 置信区间，不只报告显著性；
- 多重比较采用层级检验，探索性结果明确标记。

正式模型公式、样本规模和数值化 `delta` 属于工程试点后的确认性冻结内容。
